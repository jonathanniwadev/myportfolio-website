I'm a Software Engineer & Full-Stack Developer working independently since 2022, specializing in AI & LLM Integration. I hold a B.Sc. in Computer Science and a Diploma in Software Engineering from ISBAT University. My focus is building practical software that connects web interfaces, backend services and AI capabilities.

My technical skills include Python, TypeScript, JavaScript, React and Next.js, alongside C#, ASP.NET MVC, Entity Framework and SQL Server. I also work with PHP and Laravel. My engineering approach emphasizes component-based interfaces, API integration, database-backed workflows and clear separation between presentation, application logic and data access.

In Applied AI Engineering, I focus on integrating LLM APIs into usable applications. My focus includes language model integration, voice interactions and structured AI outputs. I'm interested in opportunities to build useful AI features and contribute across the full development lifecycle.
